# data/

Local-only working files. Everything in this folder except this README is kept out of git, because it includes staff names and direct phone lines.

- `source/community-resources.xlsx`: the original resource list, imported once in Phase 1
- `cleanup-report.md`: Phase 1 report of proposed changes and questions for the owner
- `import/`: the cleaned, approved data loaded into the database

After Phase 2, the database is the master copy. Use the admin panel's "Export to Excel" for a current spreadsheet.
